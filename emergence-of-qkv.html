How Query Key Value roles emerge

Nobody labels one matrix “the query.” The three roles appear on their own — a side effect of the network being graded on one thing.

The whole idea in one sentence: three lenses that start identical are pulled apart by differently-shaped gradients, and they only specialize when the task actually rewards asymmetry.

1Three lenses on the same word

A word arrives as a list of numbers. Three separate learned matrices — WQ, WK, WV — each reshape it. Same word in, three different vectors out. That is the only difference between query, key, and value: the numbers in their matrix.

word x = [1, 0]

Query

Q = x·WQ = [0.9, 0.1]
“what am I looking for?”

Key

K = x·WK = [0.3, 0.7]
“what do I advertise?”

Value

V = x·WV = [0.5, 0.5]
“what do I deliver?”

Nobody wrote “this one is the query.” Training sets the numbers; the roles are what those numbers end up doing.

2The worked example: why the same-looking pair drifts apart

Attention scores a match as s = Q·K. When training pushes the score, the correction each lens receives is scaled by the other lens. That is the engine of specialization — play with it:

score  s = Q·K = 12
learning rate η = 0.1
gradient to Q = ∂L/∂s × K
= -1 × 4 = -4
gradient to K = ∂L/∂s × Q
= -1 × 3 = -3

Value trains on a different circuit. V never enters the score, so it gets none of this gradient. Its correction arrives through the output blend o = a·V, scaled by how much attention a the word won. Routing (Q, K) and content (V) are learned by two different signals — which is exactly why they specialize into different jobs.

3The gradient map: same shape, different signal

Forward pass flows down; the learning signal flows back up. Follow the dashed arrows: each lens sits at a different spot, so each receives a differently-shaped correction.

Q and K meet at the score, so each one’s correction carries the other’s value — symmetric in shape, different in number. V never touches the score; it learns from the output. Three positions, three signals, three roles.

4The graph: when do the roles actually emerge?

A tiny 2-token attention, trained with real gradient descent. Both lenses start identical. We plot how far apart the query and key matrices drift, ‖WQ − WK‖, over training. The task decides whether they specialize.

Directional task — 0 must attend 1, but not the reverse Symmetric task — mutual matching

Same architecture, same identical start, same optimizer. The directional task pries the two lenses apart — query and key become genuinely different things — while the symmetric task leaves them glued together, because a single shared lens already solves it. The roles emerge only when the objective rewards them.

5What to take away

  • Q/K/V are three learned lenses, not three hand-labeled jobs. Only the matrix numbers differ.
  • Position, not intention, creates the difference. Q and K meet at the score so each gradient carries the other; V learns from the output. Different spot → different signal.
  • Symmetry has to be broken by the task. If the objective is symmetric, a shared lens survives untouched. Directionality is the pressure that forces query ≠ key.
  • Roles are the optimizer’s solution to one objective — which is why independently trained models keep discovering the same roles nobody assigned.
What the graph does not prove: a rising curve shows the lenses became different — not that a head learned any specific human concept like “grammar.” Semantic claims need input-level probing, not a divergence line.
